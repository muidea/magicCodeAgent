## 开发要求

1. 先检查项目是否完成初始化,如果未初始化需要先执行项目初始化
    * 针对web前端项目，使用 `initialization_web_project` 工具初始化项目，确保目录结构和配置文件正确生成。
    * 针对后端服务项目，使用 `initialization_service_project` 工具初始化项目，确保目录结构和配置文件正确生成。

2. 项目完成初始化后，继续进行业务模块初始化。

3. 业务模块名要求使用业务模块设计文档里对应名称的英文名，要求首字母大写。

4. 要求确保所有业务模块都完成初始化，不能出现遗漏和不符合设计的业务模块。

5. 针对web前端项目
    * 请先使用 `create_web_module` 工具进行单个业务模块初始化。
    * 所有业务模块的代码存放在`src/pages`目录下，请确保目录结构正确。
    * 根据各业务模块相关性组织文件夹结构，请勿出现无用的文件夹。

6. 针对后端服务项目
    * 请先使用 `create_service_module` 工具进行单个业务模块初始化。
    * 所有业务模块的代码存放在`internal/modules`目录下，请确保目录结构正确。

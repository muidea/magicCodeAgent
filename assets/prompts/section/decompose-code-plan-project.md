## 开发要求

1. 业务模块名要求使用业务模块设计文档里对应名称的英文名，要求首字母大写。

2. 要求确保所有业务模块都完成初始化，不能出现遗漏和不符合设计的业务模块。

3. 针对web前端项目
    * 请先使用 `create_web_module` 工具进行单个业务模块初始化。
    * 所有业务模块的代码存放在`src/pages`目录下，请确保目录结构正确。
    * 根据各业务模块相关性组织文件夹结构，请勿出现无用的文件夹。

4. 针对后端服务项目
    * 请先使用 `create_service_module` 工具进行单个业务模块初始化。
    * 所有业务模块的代码存放在`internal/modules`目录下，请确保目录结构正确。

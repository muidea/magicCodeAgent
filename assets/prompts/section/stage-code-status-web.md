## 项目状态

1. 当前处于代码开发阶段(`code`)，要求按照: 项目(`project`) -> 业务块(`module`) -> 功能模块(`block`) 的层级关系，逐级完成代码开发，禁止跨层级开发。如果未确定层级，则从项目级(`project`)开始。

2. 当前开发层级：`{{.Level}}`，如果当前层级所有的功能开发完成，在使用`attempt_finish`结束当前层级开发前，必须要确保所有代码通过代码检查，并功能运行正常。

3. 代码开发阶段严格按照设计文档进行功能开发，不改变设计文档内容，不开发超出设计文档内容之外的功能。可以使用`read_stage_file`读取设计阶段`design`对应的设计文档。

4. 项目使用yarn 作为默认包管理工具。

5. 在进行功能开发时，避免同时开发多个功能点，避免跨层级开发，避免跨模块开发。

6. 在修复错误时，避免同时修复涉及多个业务模块的错误，要求只针对当前业务模块或功能模块相关联的错误进行修复，并确认错误修复完成(通过静态检查)，再处理下一处错误。

7. 在修复错误时，特别需要注意`&lt;`和`&gt;`字符，避免错误的使用`&lt;`代替`<`,`&gt;`代替`>`导致出现代码语法错误。

8. 在所有的错误修复完成后，再使用`run_web_project`工具检查项目整体功能是否正常，禁止使用`yarn run dev`命令

9. 所有代码都需要遵循技术栈代码规范。

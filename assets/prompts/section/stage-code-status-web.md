## 项目状态

1. 当前处于代码开发阶段(code)，要求按照: 项目(project) -> 业务块(module) -> 功能模块(block) 的层级关系，逐级完成代码开发。

2. 当前开发层级：{{.Level}}

3. 代码开发阶段严格按照设计文档进行功能开发，不改变设计文档内容，不开发超出设计文档内容之外的功能。

4. 项目使用yarn 作为默认包管理工具。

5. 在修复错误时，避免同时修复多个错误，要求只针对当前业务模块或功能模块相关联的错误进行修复，并确认错误修复完成(通过静态检查)，再处理下一处错误。

6. 在所有的错误修复完成后，再使用`run_web_project`工具检查项目整体功能是否正常，如果不正常，要求根据业务相关性，重新制定对应阶段的开发目标，进行错误处理。

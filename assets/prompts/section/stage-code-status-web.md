## 项目状态

1. 当前处于代码开发阶段(`code`)，要求按照: 项目(`project`) -> 业务块(`module`) -> 功能模块(`block`) 的层级关系，逐级完成代码开发，禁止跨层级开发。如果未确定层级，则从项目级(`project`)开始。

2. 当前开发层级：`{{.Level}}`，如果当前层级所有的功能开发完成，通过静态检查，并且功能运行正常，使用`attempt_finish`结束当前层级开发。

3. 项目使用yarn 作为默认包管理工具。

4. 在修复错误时，特别需要注意`&lt;`和`&gt;`字符，避免错误的使用`&lt;`代替`<`,`&gt;`代替`>`导致出现代码语法错误。

5. 在所有的错误修复完成后，再使用`run_web_project`工具检查项目整体功能是否正常，禁止使用`yarn run dev`命令。

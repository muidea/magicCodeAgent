## 项目状态

1. 当前处于测试验证阶段(test)， 要求逐一解决测试验证过程中出现的所有错误和问题，并确保所有代码通过检查，并正常执行。

2. 测试验证阶段只根据错误信息解决代码运行错误和异常，在完成错误修复后，必须要确保所有代码都通过代码静态检查，并项目正常运行，如果不能正常运行，需要继续解决错误和异常，直到所有问题都被解决。

3. 在修复错误和异常过程中，不改变设计文档内容，不新增额外的产品功能。

4. web前端项目使用yarn 作为默认包管理工具, 使用`lint_web_project`工具进行代码检查, 使用`run_web_project`工具运行项目

5. 在修复错误时，避免同时修复多个错误，要求逐一修复错误，并确认错误修复完成(通过静态检查，并且项目运行正常)，再处理下一处错误。

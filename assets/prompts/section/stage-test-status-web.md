## 项目状态

1. 当前处于测试验证阶段(`test`)，只对错误信息进行修复，解决代码运行错误和异常，在完成错误修复后，必须要确保所有代码都通过代码静态检查，并项目正常运行，如果不能正常运行，需要继续解决错误和异常，直到所有问题都被解决。

2. 在修复错误和异常过程中，不改变设计文档内容，不新增额外的产品功能。可以使用`read_stage_file`工具读取设计阶段`design`的设计文档，读取代码开发阶段`code`的对应的源代码。

3. web前端项目使用yarn 作为默认包管理工具, 使用`lint_web_project`工具进行代码检查, 使用`run_web_project`工具运行项目，禁止直接使用`yarn run dev`命令。

4. 在修复错误时，避免同时修复多个错误，要求只针对当前业务模块或功能模块相关联的错误进行修复，并确认错误修复完成(通过静态检查)，再处理下一处错误。

5. 在所有的错误修复完成后，再使用`run_web_project`工具检查项目整体功能是否正常，如果不正常，再尝试修复错误，直到所有错误修复完成。在所有错误修复完成后使用`attempt_completion`工具结束当前测试验证任务。

## 开发要求

1. 先检查项目是否完成初始化,如果未初始化需要先使用 `initialization_web_project` 工具初始化项目，确保目录结构和配置文件正确生成。

2. 项目完成初始化后，继续进行业务模块初始化。

3. 业务模块名要求使用业务模块设计文档里对应名称的英文名，要求首字母大写。

4. 要求确保所有业务模块都完成初始化，不能出现遗漏和不符合设计的业务模块。
   * 请先使用 `create_web_module` 工具进行单个业务模块初始化。
   * 所有业务模块的代码存放在`src/pages`目录下，请确保目录结构正确。
   * 根据各业务模块相关性组织文件夹结构，请勿出现无用的文件夹。

5. 确保代码通过`lint_web_project`静态检查，无错误。如果存在错误，则要求分解新的对应层级的开发目标进行修复，直到无错误为止。

6. 确保项目使用`run_web_project`正常运行，无错误。如果存在错误，则要求分解新的对应层级的开发目标进行修复，直到无错误为止。

7. 所有代码开发完成，在通过静态检查，和确认功能正常后，请使用`attempt_completion`工具结束项目代码开发。

# 开发目标  

1. 根据设计阶段输出的业务模块清单完成业务模块代码初始化。

2. 如果对应的业务模块已经完成初始化，则核对业务模块当前实现的功能是否与设计文档描述功能一致，如果不一致则重新刷新该业务模块代码，否则使用`attempt_completion`工具结束当前业务模块代码开发，以便继续处理下一个业务模块。如果所有的业务模块已经完成初始化，则使用`attempt_completion`工具结束当前项目代码开发。

## 开发要求

1. 先检查项目是否完成初始化,如果未初始化需要先使用 `initialization_web_project` 工具初始化项目，确保目录结构和配置文件正确生成。

2. 项目完成初始化后，继续进行业务模块初始化。

3. 业务模块名要求使用业务模块设计文档里对应名称的英文名，要求首字母大写。

4. 要求确保所有业务模块都完成初始化，不能出现遗漏和不符合设计的业务模块。
   * 请先使用 `create_web_module` 工具进行单个业务模块初始化。
   * 所有业务模块的代码存放在`src/pages`目录下，请确保目录结构正确。
   * 根据各业务模块相关性组织文件夹结构，请勿出现无用的文件夹。

5. 代码开发完成后，要求对所有的代码都使用`lint_web_project`工具进行静态检查，并确保代码静态检查通过，如果存在错误，则要求根据相关分解新的开发目标进行修复，直到无错误为止。

6. 所有代码通过静态检查后，要求使用`run_web_project`工具，确保项目能正常启动，并且功能正常，如果存在错误，则要求根据相关分解新的开发目标进行修复，直到无错误为止。

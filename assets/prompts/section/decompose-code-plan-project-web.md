## 开发要求

1. 检查项目是否完成初始化,如果未初始化需要先使用 `initialization_web_project` 工具初始化项目，确保目录结构和配置文件正确生成。

2. 根据设计文档里的业务模块清单，检查所有业务模块是否全部完成初始化，不能出现遗漏和不符合设计的业务模块。
   * 使用 `create_web_module` 工具进行单个业务模块初始化。
   * 所有业务模块的代码存放在`src/pages`目录下，请确保目录结构正确。
   * 业务模块名要求使用业务模块设计文档里对应名称的英文名，要求首字母大写。
   * 根据各业务模块相关性组织文件夹结构，请勿出现无用的文件夹。

3. 必须先完成项目初始化，再进行业务模块初始化。

4. 确保代码通过`lint_web_project`静态检查，无错误。如果出现错误，则分解对应的子级开发目标进行错误修复。

5. 确保项目使用`run_web_project`正常运行，无错误。如果出现错误，则分解对应的子级开发目标进行错误修复。

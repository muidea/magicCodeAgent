## 特别注意事项

1. 在代码开发过程中，如果对同一处错误，经过多次尝试修复仍然无法解决，可以考虑对错误对应的文件根据代码功能进行全量刷新，以尝试修复错误。

2. 在错误修复过程中，要求尽量保持代码风格一致性，避免采用与当前代码实现不一致的组件或处理方式。

3. 禁止使用调整静态检查规则或直接注释代码的方式来忽略错误。

4. 在修复错误过程中，如果当前功能点已经完成修复，需要使用`attempt_completion`工具结束当前功能点，以便继续处理下一个功能点。

5. 避免反复对同一个错误进行重复性修复，如果多次修复后仍然无法解决，可以考虑使用`attempt_completion`工具结束对当前错误的修复，处理下一错误问题。

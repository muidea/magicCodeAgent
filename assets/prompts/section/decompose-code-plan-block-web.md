# 开发目标  

1. 核对当前实现的功能是否与设计文档描述是否一致，如果不一致则重新刷新对应功能的代码实现，直到代码实现完全符合设计文档要求。

2. 修复当前开发功能的代码错误，直至通过代码静态检查，并正常运行无错误。

## 开发要求

1. 要求所有代码实现符合设计要求，同时禁止添加设计以外的功能。

2. 确保模块路由信息在`.umirc.ts`里注册成功

3. 清理无用代码和引用

4. 确保代码通过`lint_web_project`静态检查，无错误。需要对功能模块内的所有错误进行修复，直到所有错误修复完成。

5. 确保项目使用`run_web_project`正常运行，无错误。需要对功能模块内的所有错误进行修复，直到所有错误修复完成。

6. 在修复代码错误时，只修复当前开发目标范围内的错误，如果无法通过仅修改功能模块内部的代码完成错误修复，则可以使用`attempt_finish`工具结束当前功能模块代码开发，分解新的功能开发目标进行下一步处理。

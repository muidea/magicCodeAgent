# 开发目标  

1. 根据设计文档，完善当前业务模块代码，确保业务模块的功能点全部实现，符合设计要求。

2. 修复业务模块的代码错误，直至通过静态检查，并正常运行无错误。

3. 完成业务模块路由和菜单注册。

## 开发要求

1. 所有界面显示的代码，包含在业务模块目录的`index.tsx`文件中，可以在component目录定义组件，并进行引用。

2. 要求根据设计文档补充业务模型定义和数据格式化函数，对应的代码包含在业务模块目录下`./types`目录

3. 业务模块对应的model定义和开放接口，包含在业务模块目录下`model.ts`文件中。

4. 业务模块对应的service定义和实现，包含在业务模块目录下`service.ts`文件中。

5. 在代码开发过程中，要求严格参照当前代码实现，在`model.ts`和`service.ts`补充新的业务功能，但不允许修改、删除已有功能。

6. 代码开发完成后，需要在`.umirc.ts`里完成业务模块的路由信息注册。

7. 严格按照设计文档描述内容进行开发，不可以改变设计文档内容和开发设计外的功能。

8. 禁止在module层级修复单一功能模块内部的错误，该种情况要求通过分解下一级开发目标进行单独处理。

9. 在修复代码错误时，只修复当前开发目标范围内的错误，并确保静态检查通过。

10. 确保代码通过`lint_web_project`静态检查，无错误。

11. 确保项目使用`run_web_project`正常运行，无错误。

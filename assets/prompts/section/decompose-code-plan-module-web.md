## 开发要求

* 要求根据设计文档补充界面显示代码开发，所有界面显示的代码，包含在业务模块目录的`index.tsx`文件中。

* 要求根据设计文档补充业务模型定义和数据格式化函数，对应的代码包含在业务模块目录下`./types`目录

* 业务模块对应的model定义和开放接口，包含在业务模块目录下`model.ts`文件中。

* 业务模块对应的service定义和实现，包含在业务模块目录下`service.ts`文件中。

* 在代码开发过程中，要求严格参照当前代码实现，在`model.ts`和`service.ts`补充新的业务功能，但不允许修改、删除已有功能。

* 代码开发完成后，需要在`.umirc.ts`里完成业务模块的路由信息注册。

* 严格按照设计文档描述内容进行开发，不可以改变设计文档内容。

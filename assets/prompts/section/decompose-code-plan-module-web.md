# 开发目标  

1. 根据设计阶段输出功能模块设计文档，补充当前业务模块代码，确保符合模块设计要求。

2. 如果对应的功能已经完成代码开发，则核对当前实现的功能是否与设计文档描述功能一致，如果不一致则重新刷新对应代码，否则使用`attempt_completion`工具结束当前功能代码开发，以便继续处理下一个功能点。

3. 完成业务模块路由和菜单注册。

## 开发要求

1. 要求根据设计文档补充界面显示代码开发，所有界面显示的代码，包含在业务模块目录的`index.tsx`文件中。

2. 要求根据设计文档补充业务模型定义和数据格式化函数，对应的代码包含在业务模块目录下`./types`目录

3. 业务模块对应的model定义和开放接口，包含在业务模块目录下`model.ts`文件中。

4. 业务模块对应的service定义和实现，包含在业务模块目录下`service.ts`文件中。

5. 在代码开发过程中，要求严格参照当前代码实现，在`model.ts`和`service.ts`补充新的业务功能，但不允许修改、删除已有功能。

6. 代码开发完成后，需要在`.umirc.ts`里完成业务模块的路由信息注册。

7. 严格按照设计文档描述内容进行开发，不可以改变设计文档内容。

8. 代码开发完成后，需要使用`lint_web_project`工具进行代码检查，确保代码符合规范。

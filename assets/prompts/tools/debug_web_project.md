### debug_web_project

Description: 调试前端项目

Parameters:
- name: (required) 项目名称
- restart: (optional) 是否重新开始调试

Usage:
<debug_web_project>
<name>projectName</name>
<restart>true</restart>
</debug_web_project>

Example: 重新开始调试Demo项目

<debug_web_project>
<name>Demo</name>
<restart>true</restart>
</debug_web_project>

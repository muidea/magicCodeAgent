### initialization_service_project

Description: 初始化后端服务项目，使用后端服务模版初始化后端服务项目

Parameters:
- name: (required) 项目名称
- description: (optional) 项目描述

Usage:
<initialization_service_project>
<name>projectName</name>
<description>这是一个示例项目</description>
</initialization_service_project>

Example: 初始化Demo项目

<initialization_service_project>
<name>Demo</name>
<description>这是一个示例项目</description>
</initialization_service_project>

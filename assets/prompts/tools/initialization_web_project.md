### initialization_web_project

描述：初始化前端项目，使用前端服务模板快速创建一个前端项目。

参数：
- **name**: (必填) 项目名称，表示初始化的前端项目的名称。
- **description**: (可选) 项目描述，对该项目的功能或用途进行简要说明。

使用方法：
```xml
<initialization_web_project>
<name>项目名称</name>
<description>项目描述（可选）</description>
</initialization_web_project>
```

示例：初始化一个名为 "Demo" 的前端项目

```xml
<initialization_web_project>
<name>Demo</name>
<description>这是一个示例项目</description>
</initialization_web_project>
```

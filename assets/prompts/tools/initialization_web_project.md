### initialization_web_project

Description: 初始化前端项目，使用前端服务模版初始化后端服务项目

Parameters:
- name: (required) 项目名称
- description: (optional) 项目描述

Usage:
<initialization_web_project>
<name>Demo</name>
<description>这是一个示例项目</description>
</initialization_web_project>

Example: 初始化Demo项目

<initialization_web_project>
<name>Demo</name>
<description>这是一个示例项目</description>
</initialization_web_project>

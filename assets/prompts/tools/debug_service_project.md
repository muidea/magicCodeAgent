### debug_service_project

Description: 调试后端服务项目

Parameters:
- name: (required) 项目名称
- restart: (optional) 是否重新开始调试

Usage:
<debug_service_project>
<name>projectName</name>
<restart>true</restart>
</debug_service_project>

Example: 调试Demo项目

<debug_service_project>
<name>Demo</name>
<restart>true</restart>
</debug_service_project>

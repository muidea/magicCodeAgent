## 代码开发约束

1. **遵循代码规范**：所有代码必须符合技术栈规范。

2. **避免并行开发**：不同时开发多个功能点，不跨层级或跨模块开发。

3. **聚焦错误修复**：每次只修复当前模块相关错误，确认修复完成后再处理下一处。

4. **全量刷新策略**：多次尝试修复失败时，考虑对整个文件进行功能性重写。

5. **保持风格一致**：修复错误时保持与现有代码风格一致。

6. **通过静态检查**：所有代码必须通过静态检查，禁止通过调整规则或注释忽略错误。

7. **完成功能点**：功能点修复完成后(**静态检查无错误，运行正常**)，使用`attempt_finish`结束当前功能点。

8. **全部完成检查**：按开发层级，完成所有**业务模块**和**功能模块**的代码开发，并且无错误时(**静态检查无错误，运行正常**)，使用`attempt_completion`结束开发。

9. **避免重复修复**：对同一错误多次修复失败时，考虑使用`attempt_finish`结束当前错误修复。

10. **特殊字符处理**：生成代码及修复错误时注意HTML特殊字符，避免错误地使用`&lt;`代替`<`，`&gt;`代替`>`。

11. **项目验证**：所有错误修复完成后(**静态检查无错误**)，使用`run_web_project`检查项目功能，禁止使用`yarn run dev`命令。
